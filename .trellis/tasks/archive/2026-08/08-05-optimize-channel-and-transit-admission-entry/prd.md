# PriceAI 收录入口与轻量准入改造

## 背景

卡网订阅的“提交渠道”入口不够清楚，且当前允许匿名批量提交链接，积累了大量代理铺货、高价、无用户需求的低价值来源，持续占用审核和采集资源。API 中转页同时展示“提交渠道”和“合作入驻”，两个入口语义重叠。

## 目标

1. 卡网订阅统一使用“申请收录”，明确仅接受自营店铺申请。
2. 卡网申请一次只提交一个店铺，联系方式可选，并明确 AI 相关在售商品原则上不超过 25 个。
3. 申请通过网页预申请后，可通过 QQ 或 Telegram 提供脱敏运营截图；本轮不建设图片上传。
4. API 中转页将两个平级入口合并为一个“申请收录”，站长申请为主路径，普通用户线索作为弹窗内次级路径。
5. 使用 PriceAI 现有浅绿色语义色强调收录入口，不改页面整体结构。

## 卡网申请文案与行为

- 页面按钮：`提交渠道` 改为 `申请收录`，桌面和移动端均显示完整文案。
- 弹窗标题：`申请收录自营店铺`。
- 说明明确：仅接受自营店铺；AI 相关在售商品原则上不超过 25 个；代理铺货、重复渠道或大量同质商品暂不收录；提交后通过 QQ 或 Telegram 提供脱敏运营截图。
- 表单一次只接受一个店铺入口。
- 字段调整为：店铺入口、店铺名称、联系方式、主营商品与价格优势。
- 联系方式可选，支持填写 QQ 或 Telegram。
- 提交按钮：`提交申请`。
- 成功提示引导申请人通过 QQ 补充脱敏运营截图，核验后再进入试采集和收录。

## API 中转入口

- 页面顶部只保留一个 `申请收录` 按钮。
- 默认展示站长/运营方的申请资料和联系方式。
- 弹窗内提供 `我只是发现了一个站点，提交线索` 次级动作，进入现有极简线索表单。
- 线索表单提供返回站长申请路径的动作。
- 后台继续使用“提交线索”术语，不改数据结构和审核流程。

## 视觉与响应式

- 收录按钮使用现有 `#e8f3ec` 背景、`#2f7a4b` 前景和低透明边框。
- 模型检测保持深色主操作，使用前说明保持白色次操作。
- 390px 宽度下按钮和弹窗文案不得溢出或遮挡。
- 弹窗保持 Escape 关闭、关闭按钮、初始焦点和关闭后焦点恢复。

## 范围外

- 不新增数据库字段或 migration。
- 不建设截图上传、自动自营识别、自动审批或复杂质量评分。
- 不自动清理存量提交和渠道。
- 不部署生产。

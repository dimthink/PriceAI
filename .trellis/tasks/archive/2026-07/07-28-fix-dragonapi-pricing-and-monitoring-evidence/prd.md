# 修正 DragonAPI 价格与监测证据

## 问题

- DragonAPI 的模型 `enable_groups` 包含 `plus`、`pro`、`image`，但公开 `group_ratio` 没有这些分组。采集器当前按 `1x` 兜底，产生无来源的公开价格。
- 分组可用性聚合把零样本的套餐级记录视为直接证据，遮蔽有样本的模型级公开监测，导致页面显示“样本不足”。
- 零样本未知来源记录被展示为“套餐公开监测”，证据标签不准确。

## 目标

- New API 分组倍率缺失时不生成可比较报价，不再默认 `1x`。
- 选择直接可用性证据时要求存在有效成功率和样本；没有有效直接证据时允许回退同模型公开监测。
- 未知来源、零样本记录不得标记为“套餐公开监测”。
- 重新采集 DragonAPI，失效 `plus`、`pro`、`image` 报价退出公开结果。
- 刷新生产公开快照并验证价格、监测来源与审核状态。

## 验收

- DragonAPI dry run 不再包含缺少 `group_ratio` 的 `plus`、`pro`、`image` 报价。
- 分组包含零样本直接记录和有样本模型记录时，展示有效模型监测并标记“同模型参考”。
- 生产公开页不再展示伪造的 `1.00x` 分组，监测链接指向 `/status`。
- API 中转测试、类型检查、lint 和生产 smoke 验证通过。

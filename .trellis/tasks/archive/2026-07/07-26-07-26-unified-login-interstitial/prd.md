# 统一登录中间页与 Google 网络提示

## 背景

当前未登录用户点击账户入口后会直接进入 Google OAuth 重定向链路。无法访问 Google 的用户会停留在外部网络请求中，PriceAI 无法展示说明或恢复动作，看起来像“点击没有反应”。项目已经存在登录面板，但正常访问 `/login` 时会立即跳转，因此用户只会在 OAuth 返回错误后看到它。

## 目标

- 将 `/login` 设为所有未登录流程的统一入口。
- 在离开 PriceAI 前明确说明当前仅支持 Google 登录，以及需要能够正常访问 Google。
- 保留安全的 `next` 回跳路径，登录成功后返回用户原任务。
- 提供“暂不登录，继续浏览”的站内退出路径。
- 保留并改善已有 OAuth 错误提示。
- 先完成本地桌面与移动端可视化验收；用户确认后再发布生产。

## 非目标

- 本次不新增邮箱验证码、密码注册或其他身份提供方。
- 不修改 Supabase OAuth 配置或数据库结构。
- 不改变公开浏览无需登录的产品边界。

## 用户旅程

1. 未登录用户从页头、移动端菜单、账户页、反馈或检测入口发起登录。
2. 进入 `/login?next=...`，看到登录用途、Google 登录方式和网络要求。
3. 用户选择“使用 Google 继续”后进入 OAuth；取消或失败则回到登录页并看到明确错误。
4. 用户可以选择“暂不登录，继续浏览”，返回原公开页面；若原目标是受保护账户页面，则返回首页。
5. 登录成功后回到经过校验的 `next` 路径。

## 页面结构

- PriceAI 品牌与“登录 PriceAI”标题。
- 登录价值说明：追踪反馈、保存模型检测记录。
- Google 主按钮。
- Google 网络要求提示，说明页面打不开时应检查网络环境。
- “暂不登录，继续浏览”次级入口。
- “公开价格和内容无需登录”的边界说明。
- OAuth 错误提示区。

## 验收标准

- 正常访问 `/login` 返回站内页面，不自动跳转 Google。
- 所有未登录入口先到 `/login`，不直接到 `/auth/google`。
- `next` 只接受安全站内路径，并能在 OAuth 成功后继续使用。
- 受保护的 `next` 不会成为“继续浏览”的循环目标。
- 页面在桌面和 390px 移动端无溢出、无重叠，键盘焦点清晰。
- `npm run lint`、相关测试和 `npm run build` 通过。
- 本地预览供用户确认后，生产发布必须通过 Cloudflare 候选烟测、切流和线上登录链路验证。

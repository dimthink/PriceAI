# 取消分类底价并修正异常价归类

## 背景

当前商品分类会先按标题识别产品，再按固定价格底线把低价报价改写到 `other-product`，其中部分低价 ChatGPT Plus 充值报价会降级到普通 Plus。该机制已经把真实存在的低价 CDK、短保号和 bug 渠道商品移出正确分类，同时把价格数值错误地当成产品语义。

## 目标规则

1. 分类只由标题、标签和来源类目等语义信号决定，不再由价格数值决定。
2. 标题明确表达定金、订金、补差价、占位价、下单后补款或仅用于补款时，优先归入 `other-product`，即使同时包含具体产品名。
3. `Gemini Pro` 标题即使提到 Flow，也不得仅因 Flow 被归为 `gemini-ultra`；Ultra 必须存在明确 Ultra 或对应高规格语义。
4. 移除全部 9 个产品底价和 ChatGPT Plus 低价特殊降级逻辑。
5. 更新分类版本，确保反馈与重分类记录能区分新旧规则。

## 数据流

`来源标题/价格 -> classifyOffer -> raw_offers.canonical_product_id -> 公开读模型/快照 -> 产品页与最低价`

价格仍作为报价事实参与排序，但不得作为分类输入。异常价商品通过标题语义进入 `other-product`，因此不会污染目标产品最低价。

## 范围

- 修改 `src/lib/catalog.ts` 的统一分类规则。
- 更新 `scripts/test-catalog.mjs`，覆盖异常价优先级、Gemini Pro/Ultra 和价格不改变分类。
- 保留后台全量重分类入口作为存量数据回填路径；本次不直接操作生产数据库或部署。

## 验收标准

- 同一正常商品标题在 `price=1/50/500` 时得到相同分类。
- 定金、订金、补差价、补款、占位价样本均归 `other-product`。
- `GPT Pro ... 下单后补差价` 归 `other-product`。
- `Gemini Pro 12个月成品号 包能用Flow` 归 `gemini-pro-year`。
- 明确的 `Google AI Ultra 250美元 Flow` 仍归 `gemini-ultra`。
- 低价 Plus CDK、Claude Max 20x 等正常标题回到语义分类。
- `npm run test:catalog`、lint、typecheck 和相关检查通过。
- 提供取消前后可见报价影响报告，并说明生产回填与快照刷新步骤。

## 非目标

- 不新增价格异常标记字段。
- 不改变最低价的库存、新鲜度和可用性规则。
- 不在本次本地实现中触发生产重分类或生产发布。

## 回滚

回滚本次代码提交即可恢复旧分类规则。生产环境若后续已执行全量重分类，回滚代码后需再次调用后台重分类入口并刷新公开快照。
